## 2. “全部功能可达”的三层保障

1. **手机版 UI（现有）**：只有 4 页，只能当"入口"，不能当"全部"；
2. **App 模式 UI（区块 8）**：网站新增底部 Tab 版导航，把上表 5~28 行全部挂上可达路径 —— 这是主方案；
3. **桌面版兼容**：确实放不下的（如 Django admin 后台）允许降级到桌面布局，但必须有入口、能操作。

## 3. 尚存的不确定性（待实机验证）

| 项 | 风险 | 验证方式 |
|---|---|---|
| 全景图 WebGL | 低端机纹理上限 / GPU 告警 | 真机打开 `/#/panorama`，看是否黑屏；告警时降层级 |
| SurveyJS 问卷编辑 | 手机屏小、拖拽困难 | 真机做一次"新建问卷 + 作答" |
| tus 大文件上传 | 切后台/息屏可能中断 | 传一张 8 MB 原图，中途锁屏 |
| Live2D | 60 MB 素材在 3 M 带宽下很慢 | 默认关，WiFi 下可开 |
| 弱命令 WebView | 部分国产机 WebView 版本旧（<80）不支持可选链 | 检测 WebView 版本，低于阈值提示升级"Android System WebView" |

## 4. 维护规则

- 网站新增路由 → 同步在本表加一行（网站仓库的 PR 里一起改，或由 App 侧跟进）；
- 每行状态从 ⏳ 变 ✅ 时，必须注明验证人 + 验证日期 + 机型；
- 本表是验收清单，不允许"默认已支持"。
