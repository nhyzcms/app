# 人工回归清单（REGRESSION）

> **为什么需要这份清单**：App 的关键路径（真实 WebView 渲染、TLS 握手、相机、文件选择器、
> 前台服务保活）没法在 CI 里自动验；而这个项目已经出过 5 次"代码全绿、真机不可用"的事故。
> 所以每次改动后按受影响的分组跑，**发版前全跑一遍**。
>
> - 自动化部分：`bash scripts/verify.sh`（静态预检 + 单测 + 壳级启动测试），见 [BUILD.md](BUILD.md)。
> - 本清单覆盖自动化**验不到**的部分，逐条都有「操作步骤 → 预期结果」。
> - 每条前面是复选框：通过打 `x`，失败写现象与机型，并开 issue/PR。
> - 状态图例同 [FEATURE-MATRIX.md](FEATURE-MATRIX.md)：🟡 表示"代码就绪、尚未真机验收"。

## A. 启动与基础（每次改动都跑，约 3 分钟）

- [ ] **A1 冷启动不闪退** — 杀掉进程后从桌面图标冷启动 3 次。
  **预期**：每次都能进站；无闪退；若闪退，下次启动会弹出可复制的崩溃记录（`CrashReporter`）。
- [ ] **A2 首屏不白屏/不黑屏** — 冷启动时观察首帧。
  **预期**：先看到骨架屏（纯色块），网页画出来后骨架自动消失；**绝不出现**全屏纯黑/纯白超过 5 秒。
- [ ] **A3 硬看门狗** — 打开飞行模式后冷启动。
  **预期**：12 秒内骨架被揭开并显示原生错误面板（不再一直盖着）。
- [ ] **A4 错误面板文案** — 断网启动 / 访问 `http://8.153.145.175/`。
  **预期**：断网显示"网络"类文案；明文 `http://` 被拦并提示；点「重试」能重新加载，点「用浏览器打开」能交给系统浏览器。
- [ ] **A5 返回键** — 站内跳 2 层后连按返回。
  **预期**：先回上一页；回到首页再按一次提示"再按一次退出"；再按才退出。错误面板可见时按返回是**收起面板**，不退出 App。
- [ ] **A6 深链** — 用 `adb shell am start -a android.intent.action.VIEW -d "https://8.153.145.175/#/m/news"` 拉起。
  **预期**：App 打开并落在该路由，不新开一个 App 实例。
- [ ] **A7 下拉刷新** — 页面滚到中部继续下拉，再滚回顶部下拉。
  **预期**：中部不触发刷新；顶部下拉出现刷新圈并能刷新。
- [ ] **A8 证书链（老设备必测）** — 老设备上首次打开站点。
  **预期**：不出现"证书不受信任"；若出现，记录机型与内核版本 —— 这是 R46 根证书问题（见 [FIX-20261012-CERT-R46.md](FIX-20261012-CERT-R46.md)）。

## B. 浏览与全部入口可达（对照 FEATURE-MATRIX，约 10 分钟）

> 这一组验的是"**不存在只能从桌面版进、在手机上进不去**的页面"。

- [ ] **B1 手机版首页 / 新闻 / 活动 / 教程** — 底部 Tab 逐个点。
  **预期**：列表能滚动、详情能打开、封面图显示（走缩略图，不拉原图）。
- [ ] **B2 任务** — 首页宫格「任务」→ 列表 → 详情。
  **预期**：可打开；管理员能看到新建/编辑入口（富文本编辑器在 6 寸屏不可用属已知限制）。
- [ ] **B3 待办 / 审核台** — `/#/m/inbox`、`/#/m/review`。
  **预期**：有权限的账号能看到条目并能完成一次通过/驳回。
- [ ] **B4 通知中心** — `/#/m/notifications`。
  **预期**：能打开、未读能标记已读。
- [ ] **B5 私信** — 「我的」→ 私信 → 进入某个会话 → 发一条文字。
  **预期**：桌面版式但可用；发送成功后消息出现在气泡里。
- [ ] **B6 个人中心 / 他人主页** — 「我的」→ 个人资料；点他人头像。
  **预期**：能打开、能改昵称/头像（头像上传走 C 组）。
- [ ] **B7 「更多」组四个入口** — 考试看板 / 课表 / 全景图 / 关于我们。
  **预期**：都能从「我的」→「更多」进入；页面可操作（桌面版式允许降级）。
- [ ] **B8 全景图（WebGL）** — 打开任一全景图并拖动。
  **预期**：能渲染、能旋转（这是手机上最容易翻车的 WebGL 场景）。
- [ ] **B9 管理员后台** — 管理员账号 →「我的」→ 进入后台管理。
  **预期**：能进 `/admin/`、能滚动（桌面布局，刻意不做移动化）。
- [ ] **B10 空问卷/问卷编辑** — 活动问卷的"回答"页。
  **预期**：SurveyJS 表单能渲染、能提交（编辑器移动化明确不做）。

## C. 上传 / 下载 / 媒体（约 8 分钟）

- [ ] **C1 文件选择** — 任一上传入口选"文档"。
  **预期**：系统文件选择器打开；选完能上传成功。
- [ ] **C2 拍照直传** — 同上，选"拍照"。
  **预期**：首次弹相机权限；拍照后能上传（拒绝权限时给中文引导，不白闪）。
- [ ] **C3 多图上传** — 新闻配图一次选 3 张。
  **预期**：3 张都能传完（tus 分段上传不中断）。
- [ ] **C4 超大文件前置提示** — 选一个 > 20 MB 的文件。
  **预期**：上传前就提示体积超限，不白等。
- [ ] **C5 下载** — 管理员导出一次审核数据 / 下载一个附件。
  **预期**：落到下载目录，通知栏可见；登录态下也能下（Cookie 已带上）。
- [ ] **C6 长按菜单** — 长按图片、长按链接。
  **预期**：图片可保存/分享；链接可复制/浏览器打开；长按文字仍是系统选择菜单。
- [ ] **C7 外链** — 点一个站外链接。
  **预期**：交给系统浏览器打开并提示；清单开关 `externalLinkInBrowser=false` 时在壳内打开（可在测试清单里临时改）。

## D. 消息、通知与角标（改动了 push/通知/前台服务才必跑）

- [ ] **D1 前台实时** — A 机登录 App，B 机给 A 发私信。
  **预期**：5 秒内出现通知（新私信有声/振动）与 launcher 角标。
- [ ] **D2 后台保活** — A 机按 Home 退到后台 5 分钟后再发。
  **预期**：仍能收到（前台服务常驻；见 [FIX-20261017-BACKGROUND-PUSH.md](FIX-20261017-BACKGROUND-PUSH.md)）。
- [ ] **D3 网页红点即时刷新** — 在 `/#/m` 页面停留，B 机发私信。
  **预期**：页面红点在不刷新的情况下更新（`club:unread` 事件）。
- [ ] **D4 点通知直达** — 点通知。
  **预期**：打开对应会话且已标记已读。
- [ ] **D5 通知权限** — Android 13+ 首次登录。
  **预期**：请求通知权限；拒绝后设置里有可见的补救入口，不反复骚扰。
- [ ] **D6 省电策略** — 首次登录后的"忽略电池优化"引导。
  **预期**：能跳转系统页面；拒绝后 App 不崩、不循环弹窗。

## E. 社员身份扫码（改动了 scan/相机/UA 才必跑）

- [ ] **E1 入口** — 网页加载完成后右下角出现扫码圆钮。
  **预期**：位置在返回顶部按钮上方，不挡内容；清单开关 `showScanEntry=false` 时消失。
- [ ] **E2 权限** — 首次点扫码。
  **预期**：请求相机权限；拒绝后给中文引导并可去设置，不白闪一下。
- [ ] **E3 扫工牌二维码** — 扫一张有效工牌。
  **预期**：取景页竖屏；识别后落到 `/#/v/<码>`，显示社员信息；**不消耗核验额度**。
- [ ] **E4 扫 Code128 条码** — 扫条码版本工牌。
  **预期**：同上；8 位裸条码**不再**兼容（会提示无效）。
- [ ] **E5 无效码 / 非本站内容** — 扫一个普通网址二维码。
  **预期**：只按 [SCAN.md](SCAN.md) 的落点规则处理，绝不把扫码文本当 JS 执行。
- [ ] **E6 取消返回** — 取景页按返回。
  **预期**：回到原页面，不残留相机预览、不崩。

## F. 弱网与性能（改动 WebView / 资源 / 缓存才必跑）

- [ ] **F1 限速首屏** — 用限速工具压到 500 KB/s 后冷启动。
  **预期**：骨架在内容出现时揭开；**不出现**误报的诊断浮层；最迟 12 秒内可交互。
- [ ] **F2 零 Live2D** — 打开首页后看服务器 access.log 或抓包。
  **预期**：本次会话没有 `/static/live2d/` 请求（壳侧兜底 + 网站按视口不挂载）。
- [ ] **F3 不重复下载** — 连续冷启动 3 次同一页面。
  **预期**：第 2、3 次静态资源基本走缓存（除非清单要求强制刷新入口）。
- [ ] **F4 设备档位** — 低内存设备上查看 `diag/last-run.txt`。
  **预期**：档位判定正确；无频繁 `trimMemory` 清缓存记录。
- [ ] **F5 滚动流畅度** — 首页/新闻列表快速滑动。
  **预期**：无明显掉帧；状态栏颜色跟随深色/浅色切换。

## G. 三级更新（改动更新链路 / 发版才必跑）

- [ ] **G1 L0 网站热更新** — 只改网站，不发 APK。
  **预期**：重开 App 看到新页面（入口 HTML 不被 WebView 缓存卡住）。
- [ ] **G2 L1 清单开关** — 改 `manifest.json` 的 `showScanEntry=false` / `startRoute`。
  **预期**：重开 App 后生效；清单拉取失败时静默用缓存，不影响启动。
- [ ] **G3 L2 升级** — 把 `latest.versionCode` 调高。
  **预期**：提示更新 → 下载有进度 → 能调起系统安装器；**sha256 不匹配时拒绝安装并告警**。
- [ ] **G4 断点续传** — 下载中途杀进程再进。
  **预期**：能续传或重下，不产生装不上的残包。
- [ ] **G5 签名一致性** — 用旧签名包装新 APK（或反过来）后尝试升级。
  **预期**：提示"签名不一致"并拒绝安装（见 [deploy/signing-fingerprint.txt](../deploy/signing-fingerprint.txt)）。

## H. 安全红线（改动 WebView 配置 / 导航 / 文件 / JS 桥才必跑）

- [ ] **H1 文件访问关闭** — 在页面里执行 `file:///etc/hosts` 类链接。
  **预期**：被拦，不显示本地文件。
- [ ] **H2 明文拦截** — 点 `http://` 链接。
  **预期**：被拦并提示（`usesCleartextTraffic=false` + `NavPolicy`）。
- [ ] **H3 TLS 失败不 proceed** — 用一个自签证书域名测试（或看 [WebShellClient](../app/src/main/java/com/nhyzcms/clubapp/shell/WebShellClient.kt) 的 `onReceivedSslError`）。
  **预期**：只 `cancel()`，显示 TLS 文案；绝不继续加载。
- [ ] **H4 上传目录活跃内容** — 打开一个 `/media/**.html` 或 `.svg` 的顶层链接。
  **预期**：不去顶层导航（`ActiveContentPolicy` 拦截），走下载/长按。
- [ ] **H5 无 JS 桥** — 代码里没有 `addJavascriptInterface`。
  **预期**：`grep -rn addJavascriptInterface app/src/main` 为空；壳内执行的只有常量脚本。
