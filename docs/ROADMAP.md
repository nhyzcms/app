# 任务路线图（ROADMAP）

> 本项目**分块开发**：每块一个 PR，块结束时向用户交一份 `docs/chunks/CHUNK-0N-REPORT.md`，
> 用户验收后再开下一块。原则：**先搭骨架，再填能力，最后打磨体验。**

---

## 推进方式

1. 每块 = 一个分支（`feat/NN-xxx` 或 `fix/NN-xxx`）+ 一个 PR；
2. 代码改动都在**本仓库**；涉及网站侧的（区块 8）在**网站仓库**单独 PR；
3. 每块的完成标准 = “交付物齐备 + 验收标准可复现 + CHUNK 报告已写”；
4. 需要动服务器/密钥的操作（签名 keystore 生成、nginx location）会在报告中单列，**等用户确认**。

## 2026-10-12 真机联调：三起故障与修复（全部已合并）

首次真机安装暴露了三个叠加的故障，已逐一修复并真机验证通过。它们都不是“功能没写完”，
而是**真机环境才会暴露的底层约束**，因此把结论沉淀成下面两节的待办与红线。

| # | 现象 | 根因 | 修复 | 状态 |
|---|---|---|---|---|
| 1 | 点开 App 约 1 秒闪退，每次必现 | 更新检查在**后台线程**读 `webView.settings`；`AOSP WebView.checkThread()` 在 targetSdk ≥ 18 时**直接抛 RuntimeException**，后台线程未捕获 → 进程被杀 | PR #10：UA 在主线程取好再进线程（`userAgentOnMainThread()`）；顺带加装**崩溃自记录**（下次启动弹窗可复制/分享） | ✅ 已验证 |
| 2 | 修复闪退后：进 App 一片黑（深色模式）/ 一片白（浅色模式） | 首屏**骨架浮层永不揭开**：唯一揭开点 `onPageFinished` 要等网页 `load` 事件（所有子资源：首页大图、live2d…），3 M 上行下迟迟不来；骨架屏又是**资源色**（深色 `#080F17`／浅色 `#FFFFFF`），不跟随运行时配色 | PR #11：绝不隐藏 WebView、不做 alpha 动画，改按 DOM 内容探测揭开；PR #12：加**12 s 纯计时硬看门狗**（不依赖 JS 回调）、**壳侧 HTTP 探测**、诊断浮层与轨迹落盘 | ✅ 已验证 |
| 3 | 骨架揭开后仍然空白 | 服务器证书链的**根** `Sectigo Public Server Authentication Root R46`（2021 年新建）**不在老设备信任库里** → TLS 握手失败 → WebView 连文档都没建（`地址：(空)`、`body 0`） | PR #13：把 R46 根作为**额外信任锚**打进 App（`res/raw/sectigo_r46.pem` + `network_security_config` 的 base-config **与 debug-overrides 两处**，后者是替换语义） | ✅ 已验证 |

### 验收结论（2026-10-12）

**区块 1~4 已由管理员在真机上全部验收通过，无遗留问题**（三个故障修好后一次性过：
能正常进站、能登录、能返回上一页、`http://` 被拦、TLS 错误有明确提示、
双击返回退出、下拉刷新手势、文件选择/拍照/下载/长按菜单等能力齐备）。

### 这一节沉淀的工程红线（写进后续所有区块的验收）

1. **WebView 只能在主线程访问**（`webView.settings` 也算）；后台线程需要的值必须在主线程取快照。
2. **不要把关键兜底挂在异步回调上**：回调可能永远不来（没有文档、JS 被禁、渲染进程异常），兜底必须纯计时。
3. **浮层一定要保证会被撤掉**，且不要用“资源色”去做全屏覆盖（它不跟随运行时配色）。
4. **判断“页面能看了”不能只看 `onPageFinished`**（它绑定 `load` 事件）；要问 DOM 内容。
5. **证书链的根也要考虑新旧**：面向学生群体，必须以“最老的设备”为准（见下方跨仓库待办）。

    是最大的两项，而 JS/CSS 只有 74 KB —— 图片是弱网下的唯一大头；
  - 讨论并落地“App 模式”下更轻的首页（减少同时发起的 API 与图片请求数）。

## 跨仓库待办：站点证书链与域名（需管理员决策）

2026-10-12 第 3 起故障查出的底层问题：站点证书链完整（叶子 ← `ZeroSSL RSA DV SSL CA 2`），
但**根是 2021 年新建的 `Sectigo Public Server Authentication Root R46`**，老设备（实测
HUAWEI P40 Pro+ / HarmonyOS 4.2 = Android 12 内核）的系统信任库里没有它 → 握手失败。

- **App 侧**已用“额外信任锚”兜住（PR #13），保证 App 可用；
- **但其它客户端（尤其是学生手机的浏览器）仍会提示“证书不受信任”**，App 改不了；
- 两个方向：
  1. 换一张链到**老根**（如 `USERTrust RSA Certification Authority`）的证书（若 CA 提供 alternate chain）；
  2. **上域名 + Let's Encrypt（推荐）**：ISRG Root X1 覆盖 Android 7.1.1 以上全部设备，
     顺带解决 App Links 官方校验（当前用 IP 无法用 `assetlinks.json` 做校验）；
- **时机**：当前证书 **2026-11-26 到期**，正好是换链的窗口；换链后需同步复核 App 侧的信任锚清单。
